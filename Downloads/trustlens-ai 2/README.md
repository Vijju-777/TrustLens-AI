# TrustLens AI — Analyze Before You Trust

AI-powered cyber safety platform: scam message analyzer, website trust
analyzer, QR code safety scanner, digital arrest scam detector, and a
cyber safety chatbot — all powered by Google Gemini.

This README covers everything needed to run the project **locally on your laptop**.

---

## 0. Prerequisites

Install these first:

| Tool | Version | Check with |
|---|---|---|
| Node.js | 18+ | `node -v` |
| Python | 3.11+ | `python3 --version` |
| Git | any | `git --version` |
| Tesseract OCR | any | `tesseract --version` |

**Install Tesseract OCR** (required for the Digital Arrest Scam Detector):
- Windows: download installer from https://github.com/UB-Mannheim/tesseract/wiki, then add its install folder to your PATH.
- macOS: `brew install tesseract`
- Linux (Debian/Ubuntu): `sudo apt-get install tesseract-ocr`

**Install zbar** (required for QR decoding via pyzbar):
- Windows: pyzbar ships the DLL — no extra step usually needed.
- macOS: `brew install zbar`
- Linux: `sudo apt-get install libzbar0`

## 1. Get your free Gemini API key
1. Go to https://aistudio.google.com/apikey
2. Sign in, click "Create API Key".
3. Copy the key — you'll paste it into the backend `.env` file below.

## 2. Set up MongoDB Atlas (free tier)
1. Go to https://www.mongodb.com/cloud/atlas/register and create a free account.
2. Create a free "M0" cluster.
3. Under **Database Access**, create a user with a password.
4. Under **Network Access**, add IP `0.0.0.0/0` (allow from anywhere — fine for a hackathon demo).
5. Click "Connect" → "Drivers" → copy the connection string. It looks like:
   `mongodb+srv://<user>:<password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority`

## 3. Backend Setup (FastAPI)

```bash
cd backend

# Create and activate a virtual environment
python3 -m venv venv
source venv/bin/activate        # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Configure environment variables
cp .env.example .env
```

Now open `backend/.env` and fill in:
```
GEMINI_API_KEY=your_actual_gemini_key
MONGODB_URI=your_actual_mongodb_connection_string
ALLOWED_ORIGINS=http://localhost:3000
```

Run the backend:
```bash
uvicorn app.main:app --reload --port 8000
```

Verify it's running:
- Open http://localhost:8000 → should show `{"service": "TrustLens AI API", "status": "running"}`
- Open http://localhost:8000/api/health → should show `"status": "ok"` (if it shows "degraded", check your `.env` values)
- Open http://localhost:8000/docs → interactive Swagger API docs (auto-generated by FastAPI)

---

## 4. Frontend Setup (Next.js)

Open a **new terminal window** (keep the backend running in the first one):

```bash
cd frontend

# Install dependencies
npm install

# Configure environment variables
cp .env.local.example .env.local
```

`frontend/.env.local` should contain:
```
NEXT_PUBLIC_API_BASE_URL=http://localhost:8000
```

Run the frontend:
```bash
npm run dev
```

Open http://localhost:3000 in your browser. You should see the TrustLens AI landing page.

## 6. Common Issues

| Problem | Fix |
|---|---|
| `/api/health` shows `database_connected: false` | Check your `MONGODB_URI`, and that your IP is allowlisted in Atlas Network Access |
| Gemini calls fail with 502 | Check `GEMINI_API_KEY` is correct and has quota at https://aistudio.google.com |
| OCR returns empty text | Make sure Tesseract is installed and on your PATH (`tesseract --version` must work) |
| QR scan says "no QR code detected" | Make sure `libzbar`/zbar is installed for your OS (see Prerequisites) |
| CORS error in browser console | Make sure `ALLOWED_ORIGINS` in backend `.env` includes `http://localhost:3000` |
| `npm install` fails | Delete `node_modules` and `package-lock.json`, then retry with Node 18+ |

## 8. Deployment (going live)

Full click-by-click instructions — GitHub → Render (backend) → Vercel
(frontend), all on free tiers — are in **[DEPLOYMENT.md](./DEPLOYMENT.md)**.

Quick summary:
- **Backend → Render**: uses `render.yaml` at the repo root (Blueprint) and
  `backend/Dockerfile`. Set `GEMINI_API_KEY`, `MONGODB_URI`, `ALLOWED_ORIGINS`
  as environment variables in the Render dashboard.
- **Frontend → Vercel**: import repo, set Root Directory to `frontend`, set
  `NEXT_PUBLIC_API_BASE_URL` to your Render backend URL.
